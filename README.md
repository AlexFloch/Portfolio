\# Портфолио



Персональный сайт-портфолио frontend-разработчика. Адаптивный одностраничный сайт с плавными анимациями и формой обратной связи.



&#x20;\*\*Демо:\*\* \[portfolio-iota-tan-51.vercel.app](https://portfolio-iota-tan-51.vercel.app/)



!\[Скриншот сайта](./screenshot.png)



\## Разделы



\- \*\*Главная\*\* - краткое представление

\- \*\*Обо мне\*\* - информация и цели

\- \*\*Проекты\*\* - выполненные работы

\- \*\*Навыки\*\* - технологии, с которыми работаю

\- \*\*Контакты\*\* - форма обратной связи и ссылки



\## Технологии



\- React 18

\- Vite

\- Tailwind CSS

\- Framer Motion (анимации)

\- Lucide React (иконки)



\## Возможности



\- Адаптивная вёрстка для телефонов, планшетов и десктопов

\- Плавные анимации при прокрутке и наведении

\- Форма обратной связи

\- Компонентная структура на React



\## Запуск локально



```bash

git clone https://github.com/AlexFloch/portfolio.git

cd portfolio

npm install

npm run dev

```



После запуска сайт откроется по адресу, который покажет терминал (обычно `http://localhost:5173`).
